# Frontend rules

## Structure (ADR 0005)

```
src/
  app/                  bootstrap, providers, router, whole-app flow tests (app/<area>.test.tsx)
  routes/               TanStack Router file routes: thin, they compose features
  features/<feature>/   api/ components/ hooks/ schemas/ + index.ts (public surface)
  components/ui/        shadcn primitives (generated by the CLI)
  components/patterns/  composed design-kit components
  lib/                  generated API client (lib/api/gen), i18n, formatters, utils
  styles/               design tokens
```

- Imports flow `routes → features → components/patterns → components/ui → lib`. A feature imports another feature
  only through its `index.ts`.

## Data

- Server state lives in TanStack Query, URL state in search params.
- A route whose page reads server data loads it in its `loader`, through the feature's `load<X>Page(queryClient, …)`.
- `staleTime: "static"` appears only as a per-call option of `queryClient.query(...)` (use the cache when present).
  Use `staleTime: 0` to refetch before navigating. Call `queryClient.clear()` when the user changes.
- Route guards are UX. The API authorizes every request.

## UI

- Forms use `useAppForm` (TanStack Form + Zod). Failed requests render through the problem helpers in
  `lib/api/problem.ts`, mapped by Problem `code`; raw server messages stay out of the UI.
- Text: `<Trans>` in JSX, or a module-level `msg` turned into a string with `i18n._(…)`. Tagged templates with
  interpolation (`` t`…${x}` ``) break the React Compiler.
- Styling uses design tokens (`styles/tokens.css`) and honours `prefers-reduced-motion`.

## Tests

- `*.test.ts` run in Node. `*.test.tsx` run in headless Chromium (Vitest browser mode), with the API mocked by MSW:
  `worker.use(<generated handler>)` from `@/test/msw` and `renderWithProviders` from `@/test/render`. Whole-app flows
  use `renderApp(path)`.
- `pnpm check` (typecheck, Oxlint, Oxfmt) and `pnpm test` pass before handing back.
