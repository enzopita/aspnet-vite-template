# 0009. CI

- Status: Accepted
- Date: 2026-11-22

## Decision

| Workflow | Runs when | Does |
|---|---|---|
| `backend` | backend inputs change | Release build (warnings as errors), OpenAPI contract unchanged, formatting, all .NET tests |
| `web` | `web/**` or `scripts/**` change | generated client and route tree fresh, typecheck, lint, format, tests, i18n, React Doctor |
| `commitlint` | pull requests | Conventional Commits in English for every PR commit |

Cost rules: path filters, one job per workflow, dependency caches, superseded PR runs cancelled, a timeout on
every job. Git hooks (lefthook) run the same gates locally, plus actionlint when workflows change.

## Consequences

Required status checks combined with path filters stay "pending" when a workflow is skipped: require checks that
always run, or add an always-running aggregator job.
