# 0004. HTTP API conventions

- Status: Accepted
- Date: 2026-11-22

## Decision

- **Versioning** in the URL segment: `/api/v1/...` (Asp.Versioning).
- **kebab-case** for every path segment and query parameter: `GET /api/v1/orders/items?page-size=50`. Route
  parameter names are camelCase in code.
- **camelCase JSON**; enums as camelCase strings.
- **Errors**: RFC 9457 Problem Details with a stable machine `code` (`<module>.<entity>.<reason>`). User-facing
  text comes from the `code` (ADR 0006). Validation errors are keyed by camelCase JSON path.
- **OpenAPI** generated by `Microsoft.AspNetCore.OpenApi` at build time, one document per API version, browsable
  with Scalar in development. It is the contract for the TS client (ADR 0007), so every endpoint declares its
  responses, summary and operation id.
- Dates: `DateOnly` → `"2026-11-21"`; instants → ISO 8601 UTC.

## Consequences

An integration test enumerates all endpoints and fails on any non-kebab-case route segment or query parameter.
